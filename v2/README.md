# 香港就业市场探索器 · v2 四章版

**[英文演示入口](https://peng-fang.github.io/hk-graduate-job-guide/v2/?lang=en)** · **[简体中文入口](https://peng-fang.github.io/hk-graduate-job-guide/v2/?lang=zh-Hans)** · **[四章故事线与逐图说明](docs/四章故事线与逐图说明.md)** · **[15 分钟英文讲稿及走台](docs/15分钟英文讲稿及走台.md)**

嘉宁刚在香港读完硕士，正在探索毕业后留下工作的可能。她先找行业线索，再查岗位分布、求职风险和薪酬背景，最后调整自己的工资、工时和生活预算，形成下一步需要查证的候选方向。

## 四章路径

| 章节 | 嘉宁的问题 | 这一步的产出 |
| --- | --- | --- |
| 00 两地对照 | 两地的就业结构有什么不同？ | 值得继续查的行业线索 |
| 01 香港就业版图 | 香港有哪些行业和职业方向？ | 可用于职位搜索的关键词 |
| 02 求职风险与薪酬参照 | 投递前要查什么？ | 对求职压力的认识，以及向雇主核实薪酬的具体问题 |
| 03 求职方向探索 | 哪些方向符合我的条件？ | 随条件变化的候选清单与岗位核查事项 |

02 合并了五章版的「失业与恢复」及「性别与收入」。默认并排展示年龄失业率热力图和行业男女薪酬对照。季度失业率、危机恢复、教育组失业率、总体收入趋势、年龄劳动参与率这五张图放进两个可展开区域。合计仍有 20 张图，适合按问题探索，也方便 15 分钟演示聚焦主线。

两个参照年份分别控制各自的资料。风险观察年联动失业资料，薪酬参照年联动收入和劳动参与资料。语言切换保留筛选值、个人条件及展开状态。

## 版本与运行

本版本以主分支提交 `78632d7` 为基础，新增于独立的 `v2/` 目录。根目录继续提供[五章版](https://peng-fang.github.io/hk-graduate-job-guide/)。页脚有返回五章版的入口。

`v2/` 包含自己的页面、脚本、样式和数据副本。打开本目录的 `index.html` 即可浏览。GitHub Pages 直接提供 `/v2/` 路径，无额外构建步骤。中英文偏好存放在独立的 `hk-guide-v2-language` 本地设置中。

## 数据与来源

图表数据副本来自原项目的 `data/guide-data.js`，由《香港劳动力_整合数据集.xlsx》的六张数据表导出。网页「数据来源与统计口径」保留来源网址、调查范围、年份和行业映射说明。此版本没有新增统计数据。

需求资料为 2026Q2，工资与工时为 2016–2025 年全职雇员资料。两地行业比较保留原项目的分类合并及估计，35 岁及以上占比沿用当前版本的补数计算。不同调查的观察期及行业层级须按图下注释解读。

如持有原整合数据集，可在本目录运行导出脚本。脚本需要 Python 与 openpyxl。

```sh
python scripts/export_data.py "/path/to/香港劳动力_整合数据集.xlsx"
```

网页格式参考[组员的 Hong Kong Job Market Explorer](https://github.com/ketianli082-stack/hong-kong-job-market-explorer)。图表、筛选和四章叙事在此仓库实现。嘉宁为虚构人物，封面港景为生成示意图。
